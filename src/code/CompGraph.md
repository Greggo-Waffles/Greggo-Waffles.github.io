<h1>Computational Graphics Project</h1>
<p>Computational Graphics Final project I try to approach designing software very methodically. 
I try to figure out what I will need and work one step at a time. This is the first time I’ve worked in OpenGL. 
I have used CAD software and other design software. In this last project I got to combine my experience with CAD 
software to lay out things before I brought it into OpenGL. I started this project trying to make objects to scale. 
I did find at one point that the zoom value was distorting my perspective. 
Programming out the building I picked the simplest end to start and worked towards the more complicated end. 
I would place objects, run the code to look at the current scene and make adjustments as necessary. 
The most time-consuming part was adjusting the walls for the carousel. 
I was making tiny adjustments to get the corners to look just how I wanted them. 
Sometimes an iteration would have very rough work just to visualize how the scene looks. 
I was in a constant struggle between simplicity and realism. 
I decided to limit the number of extra basic shapes I added to only slight variations in texture detatailing.</p>
